# DashMind

Home institucional da DashMind — portal das aplicações **Ponto Eletrônico**, **Nexo** e **Opina+**.

Site estático (HTML + CSS + Three.js via CDN), sem build.

## Rodar localmente

```bash
npx serve .
```

## Deploy na Vercel

Importe o repositório na Vercel com o preset **Other** — sem comando de build, diretório de saída `.`.

## Links das aplicações

Edite o objeto `LINKS` no início do `<script type="module">` em `index.html`.
